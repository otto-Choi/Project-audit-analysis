# SAP GL 기반 ERP Risk Analytics Pipeline

**기간** 2026.04 – 2026.05 (6주)
**유형** 개인 프로젝트 (정규 스터디)
**태그** Python / Streamlit / 데이터파이프라인 / ERP / 이상탐지

---

## 한 줄 설명

SAP에서 추출한 비정형 GL 데이터를 정제·표준화하고, config 기반 Rule Engine으로 이상거래를 탐지하는 파이프라인과 전표 드릴다운 탐색 UI를 구현한 프로젝트.

---

## 배경 및 문제의식

SAP GL 데이터는 클라이언트마다 컬럼명·금액 형식·날짜 형식이 다르고, 7~10개의 분리된 테이블로 제공된다. 리스크 판단 기준도 현장마다 다르다. 매 현장마다 수작업으로 맞추는 대신, config 파일 하나만 교체하면 다른 클라이언트 데이터에도 적용할 수 있는 구조를 목표로 했다.

## 구현한 것

### 데이터 파이프라인

SAP 7개 테이블(bkpf, bseg, ska1, skat, kna1, lfa1, cskt)을 병합하고, YAML config 기반으로 컬럼 매핑·금액 형식(A/B/C형)·파생변수를 처리하는 정제 모듈. 원본 18개 컬럼에 회계연월·요일·거래 부호 등 파생변수 16개 추가. config 파일만 수정하면 다른 SAP 수출 포맷에 대응 가능한 구조.

### config 기반 Rule Engine

`anomaly_config.yaml`에 Rule, 가중치, threshold를 정의하면 코드 수정 없이 클라이언트별 기준을 적용 가능. 8개 Rule (비업무일 전기, 월말 집중 전기, 역분개, 중복 전표, 비정상 정액, 고액 수동 전기, 차대불균형, 계정별 Z-score 이상금액). 전표 라인별 Risk Score와 Risk Level(LOW/MEDIUM/HIGH) 산출. 신규 Rule 추가 시 함수 1개 + config 항목 1개만 작성하면 파이프라인 전체에 반영.

### Streamlit 탐색 UI

- **계정 탐색 탭**: 대/중/세분류 계층 선택 → 원장 조회 → 전표 클릭 → 분개 드릴다운 → 상대 계정 이동 (탐색 히스토리 포함)
- **Risk View 탭**: Score 슬라이더 + Level + Flag 필터 → 고위험 거래 탐색 → 전표 인라인 조회

### Excel 조서 자동 생성

CONFIG 셀 1개 수정으로 원장(AutoFilter·이상거래 하이라이팅) + 월별집계 + 전표유형별 집계 3시트 Excel 출력. 금액 천단위 서식, 헤더 스타일, 열 너비 자동 계산 포함.

## 핵심 설계 의사결정

**config 분리** — Rule과 파라미터를 YAML로 분리해 코드 수정 없이 클라이언트 대응. 현장마다 다른 리스크 기준을 코드 없이 수용하기 위한 설계.

**계정 계층 자동생성** — 계정코드 Prefix 구조를 이용해 완전한 계정과목표 없이 대/중/세분류 계층 생성. 계정과목표가 제공되지 않는 현장에도 적용 가능.

**노트북/src 분리** — 탐색·개발은 notebooks/, 생산 함수는 src/에 분리. config는 클라이언트 설정 레이어로 독립.
